# Machine Learning Roadmap

This repository is the Machine Learning pillar of the broader Data & AI portfolio. It develops a small set of connected, decision-ready cases rather than unrelated model demonstrations.

## Milestones

| Milestone | Decision | Core evidence | Status |
|---|---|---|---|
| **ML1 — Campaign Response Propensity** | Which consented customers should receive a capacity-constrained retention campaign? | Logistic baseline, simple tree, tree-based champion, temporal validation, calibration, lift, economics, explainability, model card, and monitoring | **Complete** |
| **PayWave — Inactivity Risk Prioritization** | Which customers should receive limited retention outreach based on their risk of becoming inactive? | A second supervised case with temporal evaluation, capacity-aware comparison, executive deck, model card, and monitoring | **Complete** |
| **ML2 — Unsupervised Customer Segmentation** | Which stable and actionable customer groups emerge beyond fixed RFM rules? | K-means baseline, Gaussian-mixture comparison, density-based challenger, bootstrap and temporal stability, personas, and activation guidance | **Complete** |
| **ML3 — Production Readiness** | How should selected models be deployed and governed responsibly? | Training/inference contracts, registry approach, monitoring, retraining, rollback, operating runbooks, executable release validation, and executive readout | **Complete** |

## Completion standard

A case study is complete when it includes a clear decision and target contract, inspectable data, reproducible code, realistic baseline, fit-for-purpose validation, decision-aware metrics, error and segment analysis, explainability, tests, a model card, monitoring, and stakeholder communication.

## Sequence

1. Complete ML1 campaign-response propensity.
2. Complete ML2 customer segmentation using the RFM/data-architecture foundation.
3. Complete PayWave as an additional supervised case for inactivity-risk prioritization.
4. Consolidate shared production controls and operating utilities in ML3.
