# Machine Learning Roadmap

This repository is the Machine Learning pillar of the broader Data & AI portfolio. It develops a small set of connected, decision-ready cases rather than unrelated model demonstrations.

## Milestones

| Milestone | Decision | Core evidence | Status |
|---|---|---|---|
| **ML1 — Campaign Response Propensity** | Which consented customers should receive a capacity-constrained retention campaign? | Logistic baseline, simple tree, tree-based champion, temporal validation, calibration, lift, economics, explainability, model card, and monitoring | **Complete** |
| **ML1 Transfer — PayWave Inactivity** | Does the supervised framework transfer to retention-risk prioritization? | Adapt the completed PayWave case while preserving leakage-safe temporal evaluation | Planned |
| **ML2 — Unsupervised Customer Segmentation** | Which stable and actionable customer groups emerge beyond fixed RFM rules? | K-means baseline, Gaussian-mixture comparison, density-based challenger, stability, personas, and activation guidance | Planned |
| **ML3 — Production Readiness** | How should selected models be deployed and governed responsibly? | Training/inference contracts, registry approach, monitoring, retraining, rollback, and operating runbooks | Planned |

## Completion standard

A case study is complete when it includes a clear decision and target contract, inspectable data, reproducible code, realistic baseline, fit-for-purpose validation, decision-aware metrics, error and segment analysis, explainability, tests, a model card, monitoring, and stakeholder communication.

## Sequence

1. Complete ML1 campaign-response propensity.
2. Adapt PayWave as a transfer test for the supervised framework.
3. Build ML2 customer segmentation using the RFM/data-architecture foundation.
4. Consolidate production controls and shared utilities in ML3.
